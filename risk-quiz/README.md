# 風險管理基本能力測驗刷題 App

單一 HTML 檔，雙擊就能用；也可以裝到手機桌面變成 App。帳號資料存在 Google 試算表（GAS 後端），三個人共用同一個後端。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | App 本體（題庫、解析、考試重點全部內建，可離線使用） |
| `gas/Code.gs` | Google Apps Script 後端 |
| `manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png` | 讓網頁可以「加到主畫面」變成 App、支援離線 |

## 一、部署 GAS 後端（只要做一次）

1. 到 Google 雲端硬碟新增一個 **Google 試算表**（名稱隨意，例如「風管刷題資料」）。
2. 選單 **擴充功能 → Apps Script**，把 `gas/Code.gs` 的內容全部貼上，然後儲存。
3. 右上角 **部署 → 新增部署作業**：
   - 類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，第一次會要求授權，依畫面允許即可。
5. 複製產生的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。

> 之後若修改 `Code.gs`，要用「管理部署作業 → 編輯 → 版本：新版本」重新部署，網址才會保持不變。

## 二、把網址填進 App

**方法 A（建議）：** 用記事本打開 `index.html`，找到這一行：

```js
const GAS_URL_DEFAULT = '';
```

把網址貼進引號中。這樣傳給朋友的檔案就已經設定好了。

**方法 B：** 不改檔案，在登入畫面點「後端設定」貼上網址，或登入後到「統計 → 設定」。

## 三、登入方式

- 只要輸入帳號，**不分大小寫**（`Amy` 與 `amy` 是同一個帳號）。
- 第一次登入時，試算表會自動新增一個以帳號命名的工作表，記錄這個帳號的所有資料：
  - A~K 欄：星號題、每題作答紀錄、作答歷史、設定、統計摘要（JSON）
  - M~U 欄：每次練習／模擬考的紀錄（時間、模式、範圍、題數、答對、正確率、分數、用時、每題作答明細）
- 登入後會一直保持登入，除非自己按「統計 → 登出」。
- 沒有網路時照樣可以刷題，恢復連線後會自動同步；換手機或電腦登入同一帳號，資料會自動合併。

## 四、做成手機 App

`sw.js` 只能在 **https 網址** 上運作，所以要把整個資料夾（`gas` 資料夾除外）放到免費的靜態網站上：

- **Netlify Drop**：打開 https://app.netlify.com/drop ，把資料夾拖進去，會得到一個 https 網址。
- 或 **GitHub Pages**：把檔案放進 repository，再到 Settings → Pages 開啟。

用手機打開那個網址：

- **iPhone（Safari）**：分享 → 加入主畫面
- **Android（Chrome）**：右上選單 → 加到主畫面／安裝應用程式

裝好之後就是全螢幕 App，離線也能用。

> 只在電腦上用的話，直接雙擊 `index.html` 就可以，不需要架站。
> 有網路時 App 一律載入最新版的 `index.html`；沒網路時使用上次快取的版本。

## App 功能

- **首頁**：考試倒數、練習進度、正確率、快速開始、最弱章節（只顯示自己的進度）
- **考試重點**：15 章逐章重點、重點數字速查、公式速查，可搜尋；灰底標記＝講義必考
- **練習題**
  - 題目來源：全部題庫／講義題目（可選章節）／歷屆考古題（第 1～23 屆，可選屆別）／依章節（跨講義與考古題）／高頻題／星號題／錯題本／曾答錯
  - 作答方式：寫一題看一題解析，或全部寫完再對答案
  - 題數：10／20／30／60／全部／**無限模式**；順序：隨機／依序
  - 只出「沒做過的」或「答錯過的」
  - **模擬考**：歷屆隨機 60 題，前 40 題每題 1.5 分、後 20 題每題 2 分，限時 90 分鐘，70 分及格
  - 單選一屆＋全部題數＝整份歷屆試卷計分
- **複習速讀**：星號題、錯題、題庫瀏覽（直接顯示答案＋解析，考前快速看），可搜尋、篩章節
- **統計**：各章掌握度、各屆成績、作答紀錄、設定（考試日期、字體大小、GAS 網址）、匯出／匯入備份
- 鍵盤快捷鍵（電腦）：A~D 或 1~4 作答、→／Enter 下一題、← 上一題
