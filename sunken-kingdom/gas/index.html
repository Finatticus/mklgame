沉沒王國：雲端伺服器設定

只要設定一次。之後你和朋友在手機上註冊、你在試算表填 v 開通，就能玩，進度會自動在背景存到這份試算表。

1. 建立試算表與程式

  1. 到 sheets.new 建一份新的 Google 試算表，名字隨意（例如「沉沒王國存檔」）。
  2. 上方選單 擴充功能 → Apps Script。
  3. 把左邊 程式碼.gs 裡原本的內容全部刪掉，貼上下面這整段程式，按 儲存（磁片圖示）。

2. 部署成網頁應用程式

  1. 右上角 部署 → 新增部署作業。
  2. 左邊齒輪「選取類型」選 網頁應用程式。
  3. 執行身分：我；誰可以存取：所有人（一定要選「所有人」，手機才連得上；別人沒有你開通的帳號也登不進去）。
  4. 按 部署，第一次會要求授權：選你的 Google 帳號 → 出現「Google 尚未驗證這個應用程式」→ 點 進階 → 前往（不安全） → 允許。這是你自己寫的程式，所以 Google 會這樣提醒。
  5. 複製畫面上的 網頁應用程式網址（https://script.google.com/macros/s/……/exec）。
  6. 想確認有沒有成功：用瀏覽器打開那個網址，看到 {"ok":true,"msg":"沉沒王國伺服器運作中"} 就對了。

3. 把網址告訴遊戲（擇一）

方法 A（推薦）：把網址傳給 Claude，請它更新到網站上的 cloud_config.json。之後所有手機打開都會自動用這個網址，不用每支手機設定。

方法 B：自己在 GitHub 網站打開 mklgame/sunken-kingdom/play/cloud_config.json，按鉛筆編輯成：

{ "url": "https://script.google.com/macros/s/你的部署ID/exec" }

方法 C（臨時）：在遊戲登入畫面按「進階：伺服器網址」，直接貼上。只對那一支手機有效。

4. 開通帳號

  1. 手機打開 遊戲網址 → 「還沒有帳號？註冊」→ 輸入帳號、密碼。
  2. 回到試算表，會多一個 「帳號」 工作頁：
A 帳號B 密碼C 開通（填 v）D 註冊時間E 最後登入
你註冊的帳號密碼（不打碼）你手動填 v自動自動
  • 在 C 欄填 v 就開通，手機上按「登入」就能玩。
  • 把 v 刪掉＝停權：那支手機下次同步時會顯示「帳號未開通或已停權」，進度留在手機上但不能再同步；回到標題要重新登入。
  • 第一次登入成功後，會自動多一個 「存檔_帳號」 工作頁：第 2～4 列是存檔欄位 1～3、第 5 列共用儲藏箱、第 6 列備份（兩台裝置進度不同時，被蓋掉的那一份）。前面幾欄可以直接看職業、章節、遠征次數、金幣、經驗、最深環數；後面是完整存檔（太長會自動接到右邊的格子）。不要手動改存檔資料那幾格。

5. 手機加到主畫面

iPhone（Safari）：打開遊戲網址 → 下方「分享」→ 加入主畫面。之後從主畫面圖示打開就是全螢幕。iPhone 沒辦法鎖定方向，直拿時會提示你轉成橫向。

Android（Chrome）：打開遊戲網址 → 右上角 ⋮ → 加到主畫面／安裝應用程式。從圖示打開會自動全螢幕、鎖定橫向。

第一次打開要下載約 55 MB（建議用 Wi-Fi；會存在手機裡，之後很快、沒網路也能開）。每次有網路打開時會自動檢查新版本，有新版就自動更新後再進遊戲。

常見問題

  • 改了 Apps Script 程式之後：要「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址不會變。
  • 登入顯示「連不上伺服器」：確認「誰可以存取」是「所有人」，以及 cloud_config.json 的網址是 /exec 結尾的那個。
  • 手機跑起來卡：遊戲裡 選單 → 畫面與效能，選「低」或把 3D 解析度調低、幀率設 30。
