Vocab，英文與法文單字學習

一個帳號、兩種語言。英文和法文各自有自己的單字本、複習進度、設定、文章與遊戲紀錄，用右上角的 EN / FR 切換。

部署（全新開始）兩種語言的差異教室練習與 AIAI 設定（Claude / Gemini）單字判斷各頁面 複習規則設計原則資料結構後端 API 檔案日常更新已知限制

部署（全新開始）

  1. 建立一個新的 Google 試算表 → 擴充功能 → Apps Script，貼上 GAS.gs 全部內容並儲存。
  2. 專案設定 → 指令碼屬性，填入 AI 金鑰：ANTHROPIC_API_KEY（Claude）或 GEMINI_API_KEY（Gemini），至少一個，詳見「AI 設定」。GUARDIAN_API_KEY 為選填。
  3. 在編輯器選擇函式 forceAuth → 執行，依指示授權。
  4. 部署 → 新增部署作業 → 類型「網頁應用程式」，執行身分「我」，存取權「所有人」→ 複製 /exec 結尾的網址。
  5. 把網址貼到 js/config.js 的 GAS_URL，再上傳前端到 GitHub Pages。

試算表一開始是空的。第一次登入時，後端會替這個帳號建立四張工作表：帳號、帳號_Articles、帳號_Settings、帳號_Log。

教室

底部的「教室」分頁，英文和法文各有一套課程。所有課程、文法講義與單字庫都是預先寫好、檢查過的，不是即時用 AI 產生。

語言級別課數內容
法文A0 零基礎4法文和中文哪裡不一樣、看字就會唸（拼字與發音規則）、生存句、主詞與動詞變化的概念。完全沒學過的人先上這四課
A1 入門16問候、être / avoir、數字、冠詞與陰陽性、所有格、-er 動詞、問句、時間日期、形容詞、部分冠詞、地點介系詞、faire 與天氣、反身動詞、問路、購物、近未來與近過去
A2 基礎16複合過去式、未完成過去式、受詞代名詞、y 與 en、比較級、簡單未來式、命令式、qui / que / où 等
B1 進階14條件式、si 條件句、虛擬式、愈過去式、dont / lequel、間接引語、被動語態、副動詞、論證、職場法語
英文A26現在簡單／進行式、過去式與 used to、談未來、可數與不可數、比較級、現在完成式說經驗
B18完成式 vs 過去式、情態助動詞、零／第一／第二條件句與 wish、被動語態、關係子句、動名詞與不定詞、間接引語
B26敘事時態、第三與混合條件句、推測（must have）、未來進行／完成式、正式寫作與分詞構句、倒裝與強調句
  • 每一課：本課目標、文法說明與表格、例句、單字、情境對話、小知識、練習（選擇、填空、重組、中翻外、聽寫）與單字快問。課程開頭會連到相關的文法章節。
  • 文法講義（文法分頁）：獨立的完整講解，從「句子怎麼組成」「陰陽性」「冠詞」「動詞變化是什麼」這些基礎觀念講起，每章都有表格、可以聽的例句、常見錯誤提醒，章末可以練習。法文 28 章、英文 18 章。
  • 單元測驗與級別考試：每 4 課一次單元測驗，每個級別結束有級別考試，題目從課程練習與單字隨機抽，答對 70% 通過，每次重做都會換題。
  • 主題單字：依主題與程度整理的常用字（法文 26 個主題 630 字、英文 20 個主題 458 字），可以聽、快問、一鍵加入「單字庫 A1」等單字本。
  • 動詞變化（法文）：約 90 個動詞、8 種時態。混合練習可選時態與範圍，會記錄每個「動詞＋時態」的錯誤次數，「最常錯」可以專門練那些。
  • 發音：法文（字母、母音、鼻母音、連音…）與英文（長短母音、th、r / l、重音、連音、語調）。
  • 隨時聽、跟讀、存句子：例句與對話旁有朗讀、跟讀（打分數）與存成句子卡的按鈕。
  • 進度、測驗分數、讀過的文法章節都存在雲端，換手機也接得上。

練習與 AI

今日頁的捷徑或「練習」頁：

  • AI 情境對話：選情境（咖啡廳、問路、看醫生、面試…，或自己描述）與程度，和 AI 用外語對話。寫錯時在你的句子下方顯示「更好的說法」與中文說明；可以用說的（語音輸入）、看提示；結束後整理做得好的地方、需要修正的句子與實用句子。
  • AI 寫作批改：自由寫或按「出題」，AI 逐一指出錯誤並解釋、給修正版與更自然的寫法、估計程度，可存到「我的文章」。
  • AI 小故事：用最近加入、今天要複習或最常忘記的字寫一篇短文，生字會標出來，可朗讀、跟讀、存成文章。
  • 跟讀：先聽再唸，用手機的語音辨識比對，給分數並把沒被辨識出來的字標紅。iPhone 請用 Safari（iOS 14.5 以上）；不支援的瀏覽器會顯示說明。分數是辨識比對的結果，不等於專業的發音評分。
  • 錯題本：課程練習、測驗、動詞練習、單字快問答錯的題目自動收進來（每種語言最多 150 題），重練時答對就移出。
  • 句子卡：例句、對話、文章段落、翻譯結果、AI 回覆旁按 存成句子卡，存到「句子」單字本，詞性為「句子」，一樣進入每日複習。
  • 每日目標：今日頁顯示複習、新字、學習次數的進度與連續天數；目標在「更多 → 學習設定」調整。完成一課、一次測驗、一段 AI 練習或一輪練習各算一次學習。
  • 閃卡例句：有例句的字翻面後會顯示例句、朗讀鈕與中文翻譯。
  • 深色模式：「更多 → 外觀 → 底色」預設為「自動（跟隨手機）」，手機切換深色時自動改用夜讀配色。

AI 設定（Claude / Gemini）

所有 AI 功能都經過後端呼叫，金鑰只存在 GAS 的指令碼屬性，不會出現在前端程式碼。

指令碼屬性說明
ANTHROPIC_API_KEYClaude API 金鑰，在 console.anthropic.com 申請。API 按用量計費，和 Claude Pro / Max 訂閱是分開的，訂閱不包含 API 額度。
CLAUDE_MODEL選填，預設 claude-opus-5-5（品質最好）。想省錢可改 claude-sonnet-5-5 或 claude-haiku-5-5。
CLAUDE_EFFORT選填，low（預設，回應快、花費少）、medium、high。
GEMINI_API_KEYGemini 金鑰（有免費額度）。
GEMINI_MODELS選填，逗號分隔，依序嘗試。
AI_PROVIDER選填，claude 或 gemini。沒填時：有 ANTHROPIC_API_KEY 就用 Claude，否則用 Gemini。

Claude 請求有開啟伺服器端備援（fallbacks）：如果請求被安全分類器擋下，會自動改用其他模型重試，不需要另外處理。建議在 Anthropic Console 設定每月花費上限。

單字判斷與 AI

  • 英文：詞性依 Datamuse 的使用頻率與 Google 的權重判斷，並和翻譯出的中文對照，所以詞性與意思會一致（例如 beautiful → adj. 美麗的、still → adv. 仍然）。
  • 法文：Google 直接翻譯常因透過英文轉譯出錯（élève → 瞳孔），所以會和 Wiktionary 的釋義比對，對不上時改用字典的意思（élève → 學生、pièce → 房間）；名詞的陰陽性來自 Wiktionary。
  • 其他常見意思：意思欄下方會列出不同詞性的意思，點一下就能換。
  • 變化形提示：輸入 chevaux、mange 這類變化形時，會提示原形並可一鍵改用。
  • 改單字會重新帶入：把單字改掉後，自動帶入的意思、詞性、例句會跟著更新；自己手動改過的欄位不會被覆蓋。
  • AI 校對（需要 AI 金鑰）：用 AI 取得最常用的意思、詞性與例句，也會修正拼字。
  • AI 檢查例句：在編輯單字時，可以請 AI 檢查自己寫的例句（文法、拼字、重音、自然度），或請它給一句範例。

各頁面

今日

今天要複習的字數與「開始複習」，下面直接新增單字（輸入後自動翻譯、判斷詞性），還有拍照辨識與 AI 主題單字包，以及最近加入的字。

單字

單字本清單、全域搜尋、複習全部、循環播放、複習時間表、拖曳排序。點進單字本可以搜尋、排序、緊湊顯示、批次搬移或刪除、看字典、造句。刪除會先進垃圾桶，可以復原。

字典

「查單字」與「翻譯句子」兩個分頁。翻譯結果中的字都可以點來加入單字本。

閱讀

新聞，以及「我的文章」：貼上文章後逐段翻譯（翻好會存起來，下次不用重翻）、朗讀、書籤、群組。

更多

學習紀錄（收錄、熟練、連續天數、30 天答對率與每日長條圖）、兩個遊戲、每日新字上限、預設單字本、匯出／匯入／備份、底色與字體、提醒、登出。

複習

看單字想意思、看中文想單字、聽寫三種模式。鍵盤可用空白鍵翻面、1–4 評分、左右鍵切換。

複習規則

按鈕下次間隔難易係數
忘了10 分鐘後−0.2（最低 1.3）
困難第一次 1 天，之後 ×1.2−0.15
記得第一次 4 天，之後 × 難易係數+0.15
很熟10–15 天，或原間隔 × 係數（取較長者）+0.1（最高 3.0）

「今日待複習」＝到期的字＋還沒學過的新字（每天上限預設 20，可在「更多」調整，兩種語言各自設定）。遊戲答錯的字會立刻排進複習。

設計原則

  • 以文字與細線分隔取代一張張卡片；只有閃卡和對話框有外框。
  • 單字、標題用 Source Serif 4 襯線字，介面文字用 Inter；中文使用系統字型。
  • 淺色紙張底色（紙白／亞麻／霧灰，另有夜讀深色），每種語言只有一個強調色。
  • 線條圖示（Lucide）、不用表情符號與漸層；主要按鈕只有一種深色實心樣式。

GAS.gs後端

日常更新

  • 改後端：貼上新程式碼 → 管理部署作業 → 編輯 → 新版本（網址不變）。
  • 改前端：把 sw.js 的 VERSION 與 config.js 的 APP_VERSION 加一再上傳，使用者會看到「有新版本 → 更新」。
  • 測試其他後端：主控台執行 localStorage.setItem("vocab_api_override", "網址")。

已知限制

  • 沒有密碼：知道後端網址與帳號名稱就能讀寫該帳號。
  • 法文新聞只有摘要（franceinfo 的全文頁面無法穩定擷取）。
  • 法文單字沒有音標；陰陽性來自 Wiktionary，少數字可能查不到。
  • 每日提醒只在 App 開著時觸發。
  • 跟讀需要瀏覽器支援語音辨識（Safari、Chrome、Edge）；Firefox 不支援。
  • AI 回覆可能有錯，重要的內容請再確認。
  • Google 翻譯免費端點若失效，會改用 GAS 翻譯（較慢、有每日配額）。
