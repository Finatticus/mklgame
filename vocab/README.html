1. 從舊版升級（必讀）

⚠️ 新前端只能搭配新後端使用。請先更新 GAS，再上傳前端。順序反過來的話，App 會顯示「後端版本太舊」。
  1. 打開原本的 Google 試算表 → 擴充功能 → Apps Script，把程式碼整個換成 GAS.gs 的內容並儲存。
  2. 左側「專案設定」→「指令碼屬性」→ 新增：
    • GEMINI_API_KEY：Gemini 金鑰（必填）。舊金鑰曾寫在程式碼裡，建議到 Google AI Studio 刪掉舊的、重新產生一把。
    • GUARDIAN_API_KEY：Guardian 正式金鑰（選填，不填會用測試金鑰）。
    • GEMINI_MODELS：選填，逗號分隔的模型名稱，預設 gemini-2.5-flash,gemini-2.5-flash-lite。
  3. 在編輯器上方選擇函式 forceAuth → 執行一次，依指示授權（新版多用了翻譯服務 LanguageApp）。
  4. 部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」→ 部署。不要按「新增部署作業」，否則網址會變。
  5. 把整個資料夾（index.html、vcl.html、css/、js/、icons/、manifest.json、sw.js）上傳到 GitHub Pages。
  6. 手機打開 App：舊網址 vcl.html 會自動轉到 index.html；畫面跳出「有新版本」時點「立即更新」。建議之後把主畫面上的捷徑刪掉、從 index.html 重新「加到主畫面」。
✅ 第一次登入時後端會自動升級資料表：先把舊工作表複製成 {帳號}_backup_日期時間，再加上 ID 等新欄位。舊資料不會遺失，確認沒問題後可自行刪除備份工作表。

2. App 概觀

以「收集單字 → 間隔複習 → 遊戲／閱讀中反覆接觸」為核心的英文單字工具，介面為繁體中文、行動裝置優先，可安裝成手機 App（PWA）並可離線使用。

📥 收集單字

手動輸入（自動翻譯、詞性、音標、重複提醒）、智慧翻譯擷取、拍照 OCR、字典、新聞／文章點字加入、AI 主題單字包、CSV 匯入。

🧠 記憶複習

翻卡三種模式、SRS 間隔複習（每日新字上限）、循環播放、造句練習。

🎮 遊戲化

單字跑酷、星際雷射防禦戰；答錯的字自動排進複習。

📰 閱讀

The Guardian 雙語新聞、自定義文章（群組、翻譯快取、書籤、朗讀）。

帳號只需輸入名稱（沒有密碼）。名稱最多 30 字，不可包含 [ ] * ? / \ : ' "。

4. 系統架構與同步機制

前端（瀏覽器 / PWA）
畫面、SRS 計算、翻譯。
本機快取：單字、設定、文章、待送佇列
⇄
GAS Web App
POST JSON，以 action 分派；寫入時用 LockService 排隊。
⇄
Google 試算表
每位使用者 4 張表：單字、文章、設定、學習紀錄。
  • 所有寫入先存進本機佇列（localStorage），再依序送出。離線或失敗時保留，恢復連線、每 30 秒、或回到 App 時自動補送。右上角會顯示「N 筆待同步」。
  • 每個單字有唯一 ID（前端產生），重送不會重複新增。後端拒絕的操作會跳出提示並自動重新同步，讓畫面與雲端一致。
  • 同步：先送完佇列，再抓雲端資料。平時只抓「上次同步後有變動的單字」（增量同步）；按「同步資料」會完整重抓。
  • 單字清單快取在本機，離線也能瀏覽與複習，評分會在恢復連線後送出。

5. 功能說明

新增

  • 手動新增：輸入英文後自動填中文、詞性；同一本已有這個字會提醒。可填備註與例句。📷 拍照 OCR（第一次使用才下載辨識元件），已收錄的字會淡色顯示。
  • 智慧翻譯：英↔中雙向；結果裡的英文字可點擊加入。

單字本

  • 「今日需複習」顯示「到期幾個・新字幾個」。
  • 全域搜尋所有單字本；單字本內也有搜尋框。
  • 同步、複習全部、循環播放、緊湊／卡片模式、SRS 時間表、拖曳調整順序（順序存雲端，換手機也一樣）、建立新單字本。
  • 單字清單：音標（第一次查到後存回雲端，不再重抓）、發音、編輯（可改英文與單字本）、刪除到垃圾桶（可復原）、字典內容與字根。
  • 批次管理：全選、搬移（可直接新增單字本）、丟垃圾桶；在垃圾桶裡刪除才是永久刪除，也可一鍵清空垃圾桶。

翻卡

看英文猜中文、看中文猜英文、聽音拼寫；從「今日需複習」進入時，四個評分按鈕會依每個字當下的狀態顯示下次複習時間。

字典

Free Dictionary（音標、原音、英英釋義）＋ Google 翻譯（多重語意、例句）＋ Word Family；最近 10 筆查詢。

遊戲

跑酷（看中文選英文）、星際雷射（看中文拼英文）。結束時列出答錯的字，這些字會立刻排進今日需複習（不改變難易係數）。最高分存雲端。

閱讀

  • 自定義文章：群組（存雲端）、排序、段落合併 1–5 段、逐段翻譯（最多同時 3 段，翻好後存回雲端當快取）、朗讀、書籤。
  • The Guardian 新聞：經由 GAS 代理抓取，金鑰不會出現在前端。

設定與統計

  • 統計：總收錄、精熟、今日新增、今日待複習、連續學習天數、近 30 天正確率、近 30 天每日複習長條圖。
  • 主題單字包：AI 生成後可勾選、選單字本、一次全部加入。
  • 每日新字上限（預設 20）、預設單字本。
  • 匯出 CSV／Anki、完整備份（JSON）、匯入 CSV。
  • 字體大小、13 種主題、每日 18:00 提醒開關。

6. SRS 間隔複習

評分新間隔難易係數下次複習
忘記0−0.2（最低 1.3）10 分鐘後
困難首次 1 天；之後 ×1.2−0.15間隔天數後
簡單首次 4 天；之後 × 難易係數+0.15間隔天數後
熟悉10–15 天隨機，若原本間隔×係數更長則用較長者+0.1（最高 3.0）間隔天數後

今日需複習 = 已到期的單字 ＋ 從沒學過的新字（依加入順序，每天最多「每日新字上限」個）。垃圾桶裡的字不會出現。

7. 資料結構

{帳號}（單字）

ID, Book, English, Chinese, Notes, Timestamp, NextReviewTime, Interval, EaseFactor, POS, Example, Phonetic, Updated, Reviews, Lapses

{帳號}_Articles（文章）

ID, Title, Content, ParasPerBlock, Created, BookmarkIndex, Translations, Folder, Order

{帳號}_Settings（設定，Key / Value）

books（單字本順序）、defaultBook、folders（文章群組）、newPerDay。

{帳號}_Log（每日學習紀錄）

Date, Reviews, Correct, New

其他

遊戲最高分存在指令碼屬性 {帳號}_meteor／{帳號}_runner。只存在本機的：主題、字體、緊湊模式、文章群組摺疊狀態、字典查詢紀錄、翻譯快取。

10. 部署與日常更新

改了後端（GAS.gs）

貼上新程式碼 → 部署 → 管理部署作業 → 編輯 → 新版本。網址不變。

改了前端

  1. 把 sw.js 第一行的 VERSION 加一（例如 vp-v2.0.1），js/config.js 的 APP_VERSION 也一起改。
  2. 上傳到 GitHub Pages。使用者開 App 時會看到「有新版本 → 立即更新」。

本機測試

在瀏覽器主控台執行 localStorage.setItem("vp_api_override", "你的測試後端網址") 可改連其他後端，localStorage.removeItem("vp_api_override") 恢復。

11. 已知限制

  • 沒有密碼（依你的決定維持）：知道 GAS 網址與帳號名稱的人能讀寫該帳號。
  • 每日提醒只在 App 開著時觸發（瀏覽器限制；未使用伺服器推播）。
  • Google 翻譯免費端點為非官方介面，若失效會改用 GAS 翻譯（速度較慢、每日有配額）。
  • 兩台裝置同時離線修改同一個單字時，後送出的那台會覆蓋先送的。
  • 遊戲畫面的動態位置仍使用行內樣式（每一幀計算的位置），其餘畫面已改為 CSS class。

12. 2.0 改版內容

安全

  • Gemini 金鑰移到指令碼屬性；Guardian 經後端代理
  • 帳號名稱格式檢查
  • 所有使用者內容都經過跳脫，改用事件委派，不再把資料拼進 onclick
  • AI／翻譯／新聞代理加上每分鐘次數限制

資料正確性

  • 所有寫入（含 SRS 評分）走離線佇列，逐筆確認後才移除
  • 後端寫入加鎖；不再「先清空整張表」
  • 單字唯一 ID，重複單字提醒
  • 單字本順序、預設本、文章群組存雲端（舊本機資料自動帶入）
  • 後端拒絕時自動重新同步

效能

  • 增量同步；修改只寫受影響的列
  • 音標存回試算表、同時最多 3 個請求
  • 文章排序只改 Order 欄；段落平行翻譯
  • 翻譯結果本機快取；OCR 元件按需載入並重複使用
  • 洗牌改用 Fisher–Yates

PWA 與體驗

  • 網路優先的 Service Worker、版本化快取、更新提示
  • 離線可瀏覽與複習
  • 自訂對話框取代 alert/confirm/prompt
  • 每日新字上限、評分按鈕顯示實際間隔
  • 全域與單字本內搜尋、匯出／匯入／備份、學習統計圖
  • 主題單字包可勾選並一次加入
  • 遊戲答錯自動排進複習
