# 萬象遊藝館

多款遊戲的綜合平台：一個帳號、十萬遊戲幣，離線也能玩，有網路時自動同步到 Google 試算表。

- **圍棋**：9／13／19 路，對手是官方 KataGo 神經網路（在瀏覽器內以 WebGPU／WASM 執行），三種難度。
- **象棋**：亞洲規則（長將、長捉判負），自製搜尋引擎，入門到大師五級。
- **西洋棋**：FIDE 規則，對手是 Stockfish 19（WASM），依等級分 1350／1600／1900／2300／全力分五級。
- **迷你高爾夫**：只用推桿，八座九洞球場共 72 洞（松庭、赤岩、竹林、雪嶺、港灣、遺跡、秋楓、熔岩），起伏草皮、上下兩層、水池、熔岩、沙坑、冰面、旋轉木槳、擺錘、開合木門、滑動石閘與地下管道；九洞、十八洞、對戰（四級電腦球友或雙人同機）、單洞練習與每日挑戰，每洞星等可解鎖球款，依 WMF 計分。
- **撞球**：8 號球（WPA 規則），真實的滑動與滾動、推拉桿與側旋物理，電腦五級。
- **五子棋**：15 路，alpha-beta 搜尋加連續沖四必勝計算，三種難度。
- **21 點**：六副牌，加倍、分牌、保險、投降。
- **百家樂**：八副牌、標準補牌表，莊閒和與對子，附珠盤路與大路。
- **德州撲克**：六人無限注現金桌，六種個性的電腦玩家；依位置選起手牌、翻牌後模擬勝率與底池賠率行動，並記錄全桌每個人的入池、加注、下注與被抓詐唬次數來調整範圍（讀人）；會持續下注、二次開火、河牌詐唬、過牌加注、慢打，攤牌時揭曉詐唬，有些對手詐唬得手會亮牌。
- **大老二**：台灣規則四人桌（單張、對子、順子、葫蘆、鐵支、同花順，鐵支與同花順可切），輸家依剩牌計分，十張以上與手上的 2 加倍；電腦會拆牌、記牌，並把看不到的牌隨機分配推演到終局。
- **蒼穹戰機**：縱向捲軸射擊，海岸、山谷、沙漠、雪原、要塞五關與五隻頭目；機砲／雷射／追蹤飛彈／炸彈，地形以 CC0 航拍貼圖即時拼出，機體向量繪製；手指相對拖曳操控，依分數與過關發放遊戲幣。
- **月下白狼**：寫實 3D 倖存者（three.js）。白狼在夜林與雪原中求生 15 分鐘，六種武器各可進化、八種被動，三隻頭目；敵群以頂點動畫貼圖（VAT）實例化繪製，地形與物件為 Poly Haven 實景掃描素材；魂石商店提供局外成長。另有「狼群模式」：在十二塊領地的地圖上出征與防守，收服五種品種的狼（各有技能）一起作戰，經營食物與營地，最後打倒焚翼。
- **台灣麻將**：十六張、四人，吃碰槓、搶槓、補花，完整台數；電腦以向聽數與有效進張打牌，危險時改打安全牌。
- **踩地雷**：初級、中級、高級標準盤面，第一下必開空地。
- **2048**：依合出的最大方塊返還遊戲幣。

大廳依「棋類／牌桌／麻將／運動／益智」分類。

## 使用

- 線上版：GitHub Pages 的 `lotsgame/` 路徑。
- 安裝成 App：手機瀏覽器「加入主畫面」，或電腦瀏覽器「安裝應用程式」。第一次開啟後即可離線遊玩。
- 圍棋「高段」引擎約 53 MB，第一次選用時才下載，之後離線可用；想在飛機上玩請先連網開一局。
