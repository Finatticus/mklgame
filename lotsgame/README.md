# 萬象遊藝館

多款遊戲的綜合平台：一個帳號、十萬遊戲幣，離線也能玩，有網路時自動同步到 Google 試算表。

- **圍棋**：9／13／19 路，對手是官方 KataGo 神經網路（在瀏覽器內以 WebGPU／WASM 執行），三種難度。
- **象棋**：亞洲規則（長將、長捉判負），自製搜尋引擎，入門到大師五級。
- **西洋棋**：FIDE 規則，對手是 Stockfish 19（WASM），依等級分 1350／1600／1900／2300／全力分五級。
- **迷你高爾夫**：只用推桿，六座九洞球場共 54 洞（松庭、赤岩、竹林、雪嶺、港灣、遺跡），起伏草皮、水池、沙坑、冰面、旋轉木槳、擺錘、滑動石閘與地下管道；九洞、十八洞、單洞練習與每日挑戰，依 WMF 計分。
- **撞球**：8 號球（WPA 規則），真實的滑動與滾動、推拉桿與側旋物理，電腦五級。
- **五子棋**：15 路，alpha-beta 搜尋加連續沖四必勝計算，三種難度。
- **21 點**：六副牌，加倍、分牌、保險、投降。
- **百家樂**：八副牌、標準補牌表，莊閒和與對子，附珠盤路與大路。
- **德州撲克**：六人無限注現金桌，電腦依位置選起手牌、翻牌後模擬勝率與底池賠率行動。
- **台灣麻將**：十六張、四人，吃碰槓、搶槓、補花，完整台數；電腦以向聽數與有效進張打牌，危險時改打安全牌。
- **踩地雷**：初級、中級、高級標準盤面，第一下必開空地。
- **2048**：依合出的最大方塊返還遊戲幣。

大廳依「棋類／牌桌／麻將／運動／益智」分類。

## 使用

- 線上版：GitHub Pages 的 `lotsgame/` 路徑。
- 安裝成 App：手機瀏覽器「加入主畫面」，或電腦瀏覽器「安裝應用程式」。第一次開啟後即可離線遊玩。
- 圍棋「高段」引擎約 53 MB，第一次選用時才下載，之後離線可用；想在飛機上玩請先連網開一局。
