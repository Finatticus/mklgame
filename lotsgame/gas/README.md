# 後端設定（Google Apps Script）

只需要做一次，大約 3 分鐘。

1. 到 Google 雲端硬碟建立一份新的 **Google 試算表**（名稱隨意，例如「萬象遊藝館 帳號資料」）。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上本資料夾的 `Code.gs`，按儲存。
4. 右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按部署，第一次會要求授權（選自己的帳號 → 進階 → 前往專案 → 允許）。
6. 複製「網頁應用程式網址」（結尾是 `/exec`）。
7. 打開 `js/config.js`，把網址貼到 `GAS_URL`：

   ```js
   export const GAS_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```

8. 把 `sw.js` 的 `VERSION` 改一個新值（例如 `v1.0.1`），commit 並 push。

之後只要有人登入，試算表會自動出現：

- **帳號總覽**：每個帳號一列 — 遊戲幣餘額、總局數、勝／負／和、勝率、累計下注、淨輸贏、建立時間、最後登入、最後同步、登入次數、最後使用裝置，以及每款遊戲的局數。
- **玩家-〈帳號〉**：每個帳號一張工作表 — 上方是帳號摘要，下方逐筆列出每一局的時間、遊戲、難度、結果、下注、輸贏、結算後餘額、說明與裝置。

## 注意事項

- 之後若修改 `Code.gs`，要 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」**，網址才會套用新程式（網址不變）。
- 密碼不會以明文傳送或儲存；試算表裡只有雜湊值（該欄預設隱藏）。玩家忘記密碼時無法還原：請刪除「帳號總覽」中該列與對應的「玩家-〈帳號〉」工作表，讓玩家用同名重新建立帳號，再手動把餘額填回去。
- 管理員可以直接在「帳號總覽」修改「遊戲幣餘額」來加減遊戲幣，玩家下次同步時生效。
- 前端在沒有設定 `GAS_URL` 時是「單機模式」：一切照常可玩，只是資料只存在該裝置。
