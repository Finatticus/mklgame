# Ledger 帳簿

個人記帳網站。前端為純 HTML/CSS/JS（放 GitHub Pages），後端為 Google Apps Script + Google 試算表。
支援多帳號：每個帳號在試算表中有自己獨立的工作頁。
可在手機「加入主畫面」當 App 使用（PWA），離線時可先記帳，恢復連線後自動同步。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` `style.css` `app.js` | 前端主程式 |
| `config.js` | 填入 GAS 網址 |
| `manifest.json` `sw.js` `icon*` | PWA（加入主畫面、離線快取） |
| `gas/Code.gs` | 後端，貼到 Apps Script |

## 一、後端（GAS）

1. 新建一份 Google 試算表 → 選單「擴充功能」→「Apps Script」。
2. 刪除預設內容，貼上 `gas/Code.gs` 全部內容並儲存。
3. 上方函式選單選 `setup` → 執行，依指示授權。
4. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 部署後複製「網頁應用程式網址」（結尾為 `/exec`）。

> 之後若修改了 `Code.gs`，需「部署 → 管理部署作業 → 編輯 → 版本選『新版本』」才會生效，網址不變。

## 二、前端（GitHub Pages）

1. 打開 `config.js`，把 GAS 網址貼進 `window.LEDGER_API_URL = '...'`。
   （若留空，登入頁會多一個欄位讓使用者自己輸入網址。）
2. 將本資料夾的檔案推到 GitHub repo。
3. Repo → Settings → Pages → Source 選 `main` 分支、`/ (root)`。
4. 打開 `https://<帳號>.github.io/<repo>/`。

## 三、登入與註冊

- 輸入帳號、密碼後按 **註冊**：建立帳號並直接登入，同時在試算表新增一個以帳號命名的工作頁。
- 之後用同一組帳密按 **登入** 即可。
- 帳號：2–20 字，可用中英文、數字及 `_ . -`；密碼至少 6 個字元。
- 登入有效期 30 天。執行 GAS 的 `resetSessions` 可讓所有裝置強制重新登入。

## 四、匯入電子發票

1. 到電子發票整合服務平台，用手機條碼登入 → 手機條碼發票查詢 → 下載 CSV。
2. 在網站「明細」頁右上的匯入按鈕（或「設定 → 資料 → 匯入電子發票」）選擇檔案。
3. 預覽畫面可調整每張發票的分類、選擇記入帳戶，取消勾選不想匯入的發票。

- 同一張發票的多個品項會合併為一筆支出（含折扣、折抵）。
- 以發票號碼識別，已匯入過的發票會標示「已匯入」且無法再次勾選；即使兩台裝置同時匯入，試算表中也只會有一筆。
- 依賣方名稱與品名自動分類，規則在 `app.js` 的 `CATEGORY_RULES`，可自行增修。

## 五、小城市（存錢養成遊戲）

用月預算蓋一座城市，規則寫在 `city.js` 開頭，也可在頁面最下方「遊戲規則」查看。

- 日預算 = 月預算 ÷ 當月天數；有記帳且守住日預算得 15–25 建設點，沒記帳只得 4 點
- 超過日預算停工；超過 3 倍發生火災扣 15 點（可能燒掉最新建築）；連續守住 7 天 +20
- 25 棟建築依序解鎖；月底依結餘比例評 S / A / B / C，超支的城市會變成灰色
- 每月預算可在小城市頁個別修改（含過去月份）：改本月或未來月份時，之後尚未開始的月份一起改；之前的月份維持原值，不會回溯。過去月份只改該月
- 每座城市都不同：依帳號＋月份產生名字與地形（平原／河畔／湖濱／海港），隨月份換季（春櫻、夏綠、秋楓、冬雪），晚上會變夜景
- 建築種類依完工當天的消費組成決定（餐飲多→美食建築、交通多→車站等），完工後固定
- 天空成就：彩虹（整月無停工）、煙火（連續 7 天）、熱氣球（記帳 15 天）、飛行船（人口 150）
- 城市由紀錄即時計算，不另存進度；各月預算存在 `Users` 的 config 中

## 六、手機安裝

- iPhone：用 Safari 開啟網站 → 分享 → 加入主畫面
- Android：用 Chrome 開啟 → 選單 → 安裝應用程式

## 試算表結構

| 工作頁 | 內容 |
| --- | --- |
| `Users` | 帳號清單：`username, salt, hash, sheet, config, createdAt`（密碼為加鹽雜湊，不存明碼） |
| `<帳號名稱>` | 該帳號的記帳資料：`id, date, type, amount, category, account, note, createdAt, updatedAt` |

各帳號的分類、帳戶、預算設定存在 `Users` 的 `config` 欄。
